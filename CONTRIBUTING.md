# Contributing

Thank you for helping to keep this list useful.

## Adding a tool

Open a pull request that adds one line to the right section of `README.md`:

```
- [Name](link to the repository) – <img src="assets/icons/python.svg" alt="Python" height="16"> What it does, in one sentence. Licence.
```

The icon shows the main language. Icons are in `assets/icons` (from [Devicon](https://github.com/devicons/devicon), MIT); add one there if your language is missing.

A tool belongs here when it:

- is open source, with a licence in its repository
- has been updated in the last 18 months: a push to any branch counts, as shown by the repository's last push date
- is useful for mineral exploration: geophysics, geology, drilling, geochemistry, geostatistics, remote sensing, prospectivity or the data behind them

If the tool has a page on [XploraHub](https://xplorahub.com/directory/organisations), add it after the licence, the same way for every entry:

```
- [Name](link to the repository) – <img src="assets/icons/python.svg" alt="Python" height="16"> What it does. Licence. [XploraHub page](link to the page).
```

Add new tools at the end of their section. If a tool fits no section, say so in the pull request and we will find it a place.

## Fixing or removing an entry

Pull requests that fix a broken link, a moved repository or a wrong licence are always welcome. If a tool has not been updated in 18 months, open a pull request to move it to [No longer maintained](README.md#no-longer-maintained), or to remove it if it no longer works or is no longer useful. Move the line unchanged into the drop-down named after its section (add the drop-down if it is not there yet), and end it with `Last updated YYYY.`

When an archived tool is updated again, move it back to the end of its section and take off `Last updated YYYY.`
